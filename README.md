門診表：改大小及jpg檔

步驟一：先縮小尺寸
「預覽程式」 ➔ 「工具」 ➔ 「調整大小...」
確認「等比例縮放」有打勾，將「寬度」改為 1600，點擊「確定」。

步驟二：轉存為 JPG 並確保清晰度（關鍵！）
「檔案」 ➔ 選擇 「輸出...」（不要選儲存，要選輸出）。
「格式」 下拉選單請選擇 「JPEG」。
「品質」的滑桿。請將滑桿往右邊拉，盡量靠近「最佳」（檔案大小大約控制在 500 KB 到 800 KB 左右是完美的平衡）。
